# Ruben Albao Portfolio

A professional portfolio website built with React, Vite, and Tailwind CSS.

## Features

- Responsive design for mobile and desktop
- Profile section with hexagon design
- Skills section with progress bars (including PHP at 85%)
- Projects carousel with live previews to 4 websites
- Education timeline
- Contact form with social media integration
- Custom logo and branding

## Technologies Used

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)

## Project Setup

```sh
npm install
```

## Development

```sh
npm run dev
```

## Build

```sh
npm run build
```

## Preview

```sh
npm run preview
```
